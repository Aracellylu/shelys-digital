# Shelys Digital

Landing page responsive para Shelys Digital, una agencia de marketing digital enfocada en gestión de redes sociales, contenido estratégico, branding y diseño web.

## Contenido
- Hero principal con animación tipo chat de WhatsApp
- Métricas visuales con iconos
- Tarjetas de servicios con hover
- Método de trabajo con línea de tiempo y hover de imágenes
- Sección de resultados y llamada a la acción
- SEO básico con metadatos y datos estructurados

## Archivos
- `index.html`: página principal
- `Logo Shelys Digital - Sin fondo.png`: logo con nombre
- `Logo Shelys Digital - Sin fondo y sin texto.png`: símbolo del logo
- `Claridad de marca.png`: imagen para el método
- `Diseño que vende.png`: imagen para el método
- `Contenido con dirección.png`: imagen para el método
- `Optimización continua.jpg`: imagen para el método

## Publicación
- La página está pensada para publicarse como sitio estático.
- Usa Bootstrap 5, Bootstrap Icons, Google Fonts y CSS personalizado.
- El botón principal de contacto apunta a WhatsApp.

## SEO
- `lang` configurado en `es-ES`
- Título optimizado para marca y servicios
- Descripción, keywords y metadatos Open Graph/Twitter
- Datos estructurados en JSON-LD para buscadores

## Edición
- Si agregas nuevas imágenes, respeta el nombre de cada tarjeta para mantener el hover visual.
- Puedes ajustar textos y enlaces desde `index.html` sin necesidad de estructura adicional.
